# Orders & Products — API

NestJS backend. No application endpoints are implemented yet.

## Development

```bash
npm install
npm run start:dev
```

The server uses port 3001 by default and the `/api` route prefix.

## Checks

```bash
npm run lint
npm run build
```

Vitest unit and end-to-end configurations are retained. No tests are
implemented yet; test commands currently report that no test files were found.
